# Task Manager Web Application

A simple Task Manager web application built using HTML, CSS, JavaScript, and Bootstrap. It helps users manage their daily tasks by adding, editing, deleting, searching, and filtering tasks.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Set task title, description, due date, and priority
- Search tasks by title or description
- Filter tasks by priority
- Sort tasks by priority: High, Medium, and Low
- Save tasks in the browser using Local Storage
- Responsive design using Bootstrap
- Simple and attractive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Browser Local Storage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks.

## How to Use

1. Enter the task title.
2. Add a description if required.
3. Select a due date.
4. Choose the task priority.
5. Click **Add Task** to save the task.
6. Use the **Edit** button to update a task.
7. Use the **Delete** button to remove a task.
8. Use the search box or priority filter to find specific tasks.

## Data Storage

The application uses browser Local Storage to save tasks. The saved tasks remain available when the page is reopened in the same browser, unless the browser data is cleared.
